# Soft Darts Score 2.0 — iPad導入手順

このアプリはPWAです。最初に一度だけWebへ公開し、iPadのSafariからホーム画面へ追加します。追加後は通常のアプリのように起動でき、ゲーム記録はiPad内に保存されます。

## 1. Webへ公開する（GitHub Pages）

1. GitHubへサインインし、新しい公開リポジトリを作成します（例: `soft-darts-score`）。
2. `SoftDartsScore_PWA_v2.0.zip` を展開します。
3. 展開した中のファイルをすべて、リポジトリの一番上へアップロードします。`index.html` が一番上にある状態にします。
4. リポジトリの **Settings → Pages** を開きます。
5. **Build and deployment** の Source を **Deploy from a branch** にします。
6. Branchを **main**、フォルダーを **/(root)** にして保存します。
7. 数分後に表示される `https://ユーザー名.github.io/soft-darts-score/` を開きます。

注意: GitHub FreeではPages用リポジトリを公開設定にする必要があります。ただしゲームの投球記録は公開ファイルに含まれず、それぞれのiPad内だけに保存されます。

## 2. iPadへ追加する

1. iPadを横向きにします。
2. **Safari** で上記の公開URLを開きます。
3. Safariの **共有** ボタンをタップします。
4. **さらに表示 → ホーム画面に追加** を選びます。
5. **Webアプリとして開く** をオンにします。
6. **追加** をタップします。
7. ホーム画面の **Darts Score** アイコンを起動します。

初回はインターネット接続中に一度起動してください。その後は基本画面とゲーム機能をオフラインで利用できます。

## 3. アップデート方法

1. 新しいZIPを展開します。
2. GitHubリポジトリ内の同名ファイルを新しいファイルで置き換えます。
3. Pagesの更新完了後、iPadをオンラインにしてアプリを一度終了・再起動します。

記録はブラウザー内のLocalStorageに保存されるため、通常の上書き更新では残ります。SafariのWebサイトデータ削除やホーム画面アプリの削除は、記録が消える可能性があるため避けてください。

## 収録機能

- Cricket 2人対戦（PLAYER 1 / PLAYER 2、基本ルール、最大15ラウンド）
- Cricket 1人練習、Count-Up、301 / 501 / 701
- 3投ごとの自動交代、通常CricketのClose・加点・勝敗判定
- ラウンド・選手・投目・Marksの投球履歴
- 01 / Count-Upのラウンド別得点常時表示（100点以上はオレンジ）
- オフライン保存、途中ゲーム復帰、UNDO
